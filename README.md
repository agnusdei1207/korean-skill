# korean-skill

한국어 글을 읽기 쉽게 쓰기 위한 스킬 모음. 스킬은 `skills/` 아래에 하나씩 둔다.

| 스킬 | 다루는 내용 |
|---|---|
| [write-readable-text](skills/write-readable-text/SKILL.md) | 처음 보는 독자 기준, 결론 우선 구조, 읽기 쉬운 형태와 표현, 외부 전달 글의 의존성 제거, 종료 검수 |
| [readable-korean-sentences](skills/readable-korean-sentences/SKILL.md) | 사물·추상 명사 주어를 상태 서술로 교정 |
| [plain-factual-style](skills/plain-factual-style/SKILL.md) | 과장과 장황함을 줄이는 담백한 사실 문체, 어휘, 마크다운 서식 금지 |
| [prose-flow-and-variation](skills/prose-flow-and-variation/SKILL.md) | 문단 흐름, 문장 변주, 반복 통제, 문장 선호 사후 진단 |

한국어로 쓸 때는 write-readable-text를 기본으로 쓰고, 나머지 세 스킬은 그 스킬이 함께 쓰도록 안내한다.
