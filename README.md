|---|---|

| [readable-korean-sentences](skills/readable-korean-sentences/SKILL.md) | 사물·추상 명사 주어 문장을 상태 서술로 교정 |
| [prose-flow-and-variation](skills/prose-flow-and-variation/SKILL.md) | 문단 흐름, 문장 변주, 반복 통제 |
