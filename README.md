# korean-skill

AI가 번역투 없이 자연스러운 한국어 문장을 쓰도록 돕는 스킬 모음.

| 스킬 | 역할 |
|---|---|
| [avoid-translationese](skills/avoid-translationese/SKILL.md) | 번역투 패턴(피동 남용, ~를 가지다, ~에 대해 등)을 한국어 구조로 교정 |
| [readable-korean-sentences](skills/readable-korean-sentences/SKILL.md) | 사물·추상 명사 주어 문장을 상태 서술로 교정 |
| [prose-flow-and-variation](skills/prose-flow-and-variation/SKILL.md) | 문단 흐름, 문장 변주, 반복 통제 |
| [write-readable-text](skills/write-readable-text/SKILL.md) | 독자 기준 글쓰기: 결론 우선, 읽기 쉬운 형태, 종료 검수 |
