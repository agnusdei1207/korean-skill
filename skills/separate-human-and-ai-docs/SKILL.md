# 사람을 위한 글과 AI를 위한 글을 나눈다

사람은 정보를 풀어 이해하기 쉬운 글을 원하고, AI는 정보를 압축해 수행하기 쉬운 글을 선호한다. 한 문서에 둘을 섞지 않고, 본문은 설명 유형으로, 부록은 기록·참조 유형으로 나눠 쓴다.

## 본문 순서

1. 결론
2. 확인하려 한 것(배경)
3. 원리
4. 결과: 소제목이 발견 자체를 말하는 평서문이다.
5. 결정과 한계

## 부록으로 옮기는 것

판단에 쓰이지 않는 수치, 확인 표, 실행 명령은 지우지 않고 부록으로 옮긴다.

## 원리를 보여 줄 때

원리가 수치만으로 그려지지 않으면 실제 질의 하나의 사례 표나 그림(SVG, `figures/`)을 넣는다.

문장 단위 교정은 [write-natural-korean](../write-natural-korean/SKILL.md)을 쓴다.
