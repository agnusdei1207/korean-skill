# 번역투 없는 한국어

영어를 먼저 떠올려 문장을 만들면 영어 구조가 한국어 어휘에 얹힌다. 단어는 한국어인데 문장이 어색하면 번역투다. 한국어는 주어를 자주 생략하고, 동사·형용사 같은 용언으로 문장을 끌고 가며, 피동보다 능동을 선호한다. 이 구조로 문장을 다시 세운다.

## 쓰는 법

1. 말하려는 사실을 먼저 정하고, 영어 문장이 아니라 한국어 화자가 그 사실을 말하는 방식으로 쓴다.
2. 쓴 뒤 소리 내어 읽는다는 기분으로 걸리는 곳을 찾고, 아래 패턴과 대조해 고친다.
3. 고쳤는데도 어색하면 단어가 아니라 문장 구조를 바꾼다. 주어를 바꾸거나 생략하고, 명사로 뭉친 곳을 동사로 푼다.

## 패턴과 교정

### 피동 남용

능동으로 쓸 수 있으면 능동으로 쓴다. 이중 피동(되어지다, 보여지다, 쓰여지다, 불리워지다)은 쓰지 않는다.

| 교정 전 | 교정 후 |
|---|---|
| 이 방법이 많이 사용되어지고 있다 | 이 방법을 많이 쓴다 |
| 결과가 보여진다 | 결과가 보인다 / 결과를 보면 |
| 그는 천재라고 여겨진다 | 사람들은 그를 천재라고 한다 |
| 팀에 의해 개발되었다 | 팀이 개발했다 |

### 무생물 주어

사물이 사람처럼 행동하는 문장은 상태 서술로 바꾼다. 자세한 기준은 [읽기 쉬운 한국어 문장](../readable-korean-sentences/SKILL.md)에 있다.

| 교정 전 | 교정 후 |
|---|---|
| 이 그래프는 매출이 늘었음을 보여 준다 | 이 그래프에서 매출이 늘었음을 알 수 있다 |
| 이 설정이 오류를 방지한다 | 이 설정을 켜 두면 오류가 나지 않는다 |

### 동사를 명사로 뭉친 표현

~를 하다, ~를 가지다, ~를 행하다, ~를 필요로 하다는 동사 하나로 줄인다.

| 교정 전 | 교정 후 |
|---|---|
| 회의를 가졌다 | 회의했다 |
| 검토를 하였다 | 검토했다 |
| 영향을 가지고 있다 | 영향을 준다 |
| 지원을 필요로 한다 | 지원이 필요하다 |
| 개선이 이루어졌다 | 개선되었다 |

### 불필요한 전치사 대응어

~에 대해(서), ~에 있어서, ~을 통해(서), ~로 인해, ~로 하여금, ~에 의하면은 영어 전치사를 옮긴 흔적이다. 조사나 동사로 직접 쓴다.

| 교정 전 | 교정 후 |
|---|---|
| 이 문제에 대해 논의했다 | 이 문제를 논의했다 |
| 설계에 있어서 중요한 점은 | 설계에서 중요한 점은 |
| 실험을 통해 확인했다 | 실험으로 확인했다 |
| 비용 증가로 인해 중단했다 | 비용이 늘어 중단했다 |
| 그로 하여금 떠나게 했다 | 그가 떠나게 했다 |

### 조사 ~의 연쇄와 ~적(的)

~의가 이어지면 앞뒤를 풀어 쓴다. ~적, ~로서의, ~와의, ~로의는 풀어 쓴다.

| 교정 전 | 교정 후 |
|---|---|
| 시스템의 성능의 개선의 필요성 | 시스템 성능을 개선해야 할 이유 |
| 사용자와의 상호작용 | 사용자와 상호작용하는 방식 |
| 효율적인 운영이 가능하다 | 효율 좋게 운영할 수 있다 |

### 복수 ~들과 대명사

영어의 복수와 인칭대명사를 그대로 옮기지 않는다. 복수는 수량 표현이 이미 있으면 ~들을 붙이지 않고, 주어는 앞 문장과 같으면 생략한다.

| 교정 전 | 교정 후 |
|---|---|
| 많은 사람들이 그것들을 사용한다 | 많은 사람이 쓴다 |
| 그는 그의 방에서 그의 책을 읽었다 | 그는 방에서 책을 읽었다 |
| 사용자는 버튼을 누른다. 사용자는 화면을 본다. | 사용자가 버튼을 누르면 화면이 바뀐다. |

### 시제와 진행형

과거완료(~했었다), 진행형(~하고 있는 중이다), 현재완료(~해 왔다)를 영어 시제 그대로 옮기지 않는다. 한국어에서는 과거 하나와 현재로 충분한 경우가 많다.

| 교정 전 | 교정 후 |
|---|---|
| 이미 배포했었다 | 이미 배포했다 |
| 서버가 재시작하고 있는 중이다 | 서버가 재시작 중이다 / 재시작한다 |
| 이 서비스는 서울에 위치하고 있다 | 이 서비스는 서울에 있다 |

### 필요·가능 표현의 과잉

~할 수 있다, ~할 필요가 있다, ~하는 것이 중요하다를 모든 문장에 붙이지 않는다. 단정해도 되는 사실은 단정한다.

| 교정 전 | 교정 후 |
|---|---|
| 이 값을 확인할 필요가 있다 | 이 값을 확인한다 / 이 값을 확인해야 한다 |
| 오류가 발생할 수 있는 가능성이 있다 | 오류가 날 수 있다 |
| 테스트를 작성하는 것이 중요하다 | 테스트를 작성한다 |

### 관용구와 군더더기

| 교정 전 | 교정 후 |
|---|---|
| 둘 중에 하나 | 둘 중 하나 |
| ~라고 할 수 있다 | ~이다 (단정 가능하면) |
| ~한 바 있다 | ~했다 |
| ~에 다름 아니다 | ~이다 |
| ~에 불과하다 | ~일 뿐이다 |
| ~로서의 역할을 한다 | ~로 쓰인다 / ~이다 |

## 고치지 않는 경우

- 고유명사, 인용문, 코드, 명령어는 원문 그대로 둔다.
- 피동이 자연스러운 경우(예: 문이 닫혔다, 데이터가 저장된다)는 그대로 둔다. 행위자가 중요하지 않거나 모를 때 피동은 정상적인 한국어다.
- 법률·규정 문서처럼 관용이 굳은 문서는 그 관행을 따른다.
