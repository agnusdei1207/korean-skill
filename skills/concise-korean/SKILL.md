# 짧은 문장, 동사 중심

한국어는 서술어가 문장 끝에 붙는다. 명사화가 과하면 주어와 서술어의 거리가 멀어지고, 읽다가 숨이 막힌다. AI가 자연스럽게 쓰려다 만드는 "〜에 대한 검토", "〜의 수행" 같은 명사 나열은 한국어답지 않다.

## 규칙 1 — 명사화 → 동사
명사화로 끝난 문장은 동사로 푼다.

- "계약에 대한 검토" → "계약을 검토"
- "성공 여부의 판단" → "성공했는지 판단"
- "실행의 개선" → "실행하면서 개선"
- "사용자 요구에 의한 개선" → "사용자가 요구한 것을 개선"

## 규칙 2 — 명사 나열 끊기
"〜의 〜에 의한 〜" 3연타는 끊는다.

- "사용자 요구에 의한 시스템 개선" → "사용자가 요구한 것을 시스템이 개선"
- "기술 발전에 따른 업무 방식의 변화" → "기술이 발전하면서 업무 방식이 바뀜"

## 규칙 3 — 한 문장 한 메시지
한 문장에 주제가 둘 이상이면 마침표로 나눈다.

- "시스템이 판단하고 데이터가 저장한다" → "시스템이 판단하고, 데이터를 저장한다."

## 규칙 4 — 주어가 동작을 수행하는지 확인
사물이나 추상 명사가 사람처럼 행동하는 주어는 상태 서술로 고친다 (write-natural-korean과 공통).

- "시스템이 판단한다" → "시스템은 입력값에 따라 결과를 출력하는 상태이다"
- "데이터가 흐른다" → "데이터는 수집→처리→저장 경로를 따라 이동한다"

## 체크리스트
- [ ] 명사화를 동사로 풀었는가
- [ ] "〜의 〜에 의한" 3연타가 없는가
- [ ] 한 문장에 주제가 하나만 있는가
- [ ] 주어가 실제 동작을 수행하지 않으면 상태 서술로 고쳤는가
