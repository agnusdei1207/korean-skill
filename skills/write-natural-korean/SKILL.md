# 읽기 쉬운 한글로 교정한다

사물이나 추상 명사가 사람처럼 행동하는 주어로 쓰이면, 그 문장이 실제로 어떤 상태나 사실을 가리키는지가 빠지기 쉽다. 아래 예시는 그런 문장을 상태 서술로 고친 것이다. 고칠지 판단할 때는 주어가 그 동작을 실제로 수행하는지를 확인한다.

- 교정 전: 절마다 양식이 정해져 있어, 다른 내용이 섞이는 것을 양식이 막는다.
- 교정 후: 절마다 쓸 내용이 정해져 있어, 다른 내용이 섞이지 않는다.

- 교정 전: 표본의 20%가 제외되어 회의록이 감수하기로 한 그대로다.
- 교정 후: 표본의 20%가 제외되었으며, 이는 회의에서 감수하기로 정한 손실과 같다.

- 교정 전: 캐시 도입은 일관성 문제를 감수하는 것이며, 갱신 규칙이 따로 필요함.
- 교정 후: 캐시를 도입하면 일관성 문제는 감수해야 하며, 갱신 규칙도 따로 정해야 함.
